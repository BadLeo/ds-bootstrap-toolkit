# Security Policy

## Supported Scope

This repository is a static frontend project with no backend services, credentials, or build pipeline dependencies committed in-repo.

## Reporting A Vulnerability

Please do not open a public issue for a suspected security problem.

Instead, report:

- the affected file or page
- the steps required to reproduce the issue
- the impact you believe it has
- any suggested mitigation if you have one

Maintainers should acknowledge a report within a reasonable timeframe and decide whether the issue needs a private fix before disclosure.

## Examples Of Relevant Reports

- Cross-site scripting risks in client-side code
- Unsafe external CDN usage or integrity gaps
- Sensitive information committed to the repository
- Clickjacking, content injection, or broken link-based trust issues
